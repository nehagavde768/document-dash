# Certificate documents

5 certificates for the game. Domicile, Income and the two caste certificates follow the
Chhattisgarh Rajpatra of 28 July 2025 (rows 6–9). Marriage is unchanged from the current game.

A certificate is complete when it has one document from every **required** category.
Any one document from a category is enough.

**How to edit**

- Each line is `English name | Hindi name`.
- Add, remove or rename documents and categories. Keep one document per line.
- Change **required** to **optional** (or back) to change whether a category is needed.
- A document listed in more than one place (for example Application Form) is one card in the game.
